一、　软件概述

1.1　用途

本软件面向连锁零售企业的新员工入职培训场景，以「微信聊天式人机对练」的方式训练销售话术：学员在仿真的微信对话界面中应对由 AI 扮演的刁难客户，系统对每一轮回复实时评分，训练结束后生成五维能力报告，供学员自查、带教主管辅导与运营部门统计。

相比集中授课与角色扮演，本软件的价值在于：练习可无限次重复、评分口径统一、过程数据可留存，带教主管不必到场即可看到每位新人的短板。

1.2　适用对象

  • 新入职销售人员：完成入职培训的话术对练任务；
  • 带教主管 / 店长：查看本组学员进度与短板，撰写辅导记录、做对话质检；
  • 运营 / 培训部门：下发训练任务、维护训练场景、统计整体达标情况。

1.3　主要功能

二、　运行环境

2.1　服务端

项目要求
操作系统Windows 10/11、macOS 12+、主流 Linux 发行版
运行环境Node.js 22 及以上（内置 SQLite 驱动，无需另装数据库）
内存建议 2 GB 以上；100 人规模实测占用约 200 MB
磁盘程序约 5 MB，数据库随练习量增长（每条成绩约 2 KB）
网络局域网即可；如需外部访问建议部署在 HTTPS 之后

2.2　客户端

学员端与后台均为纯网页，无需安装客户端。推荐使用 Chrome、Edge 或任何支持 ES2020 的现代浏览器；移动端可直接用手机浏览器访问，界面按手机尺寸自适应。

语音输入依赖浏览器录音权限，需在首次使用时允许麦克风访问；不建议使用 IE 及已停止维护的旧版浏览器。

三、　安装与启动

3.1　安装

本软件为绿色部署：解压即用，无安装程序、无外部依赖（数据库、Web 服务均已内置）。

  • 将程序包解压至任意目录（路径中不建议包含空格）；
  • 确认已安装 Node.js 22 或以上版本（命令行执行 node -v 可查看版本）；
  • 无需执行依赖安装命令，程序不含第三方运行库。

3.2　启动服务

在程序目录下双击 start-server.bat（Windows）或在终端执行 node server/index.js，看到以下提示即启动成功：

服务已启动 · http://127.0.0.1:8848

如需同时启用语音识别与模拟评分服务，可双击 start-all.bat 一次性启动全部组件。

四、　学员端功能说明

学员端采用微信风格的对话界面，学员无需学习即可上手。页面分为三栏：左侧为本次训练任务与训练目标，中间为手机样式的微信对话区，右侧为「我的任务」与能力评分。

4.1　开始一次练习

  • 在左侧「本次训练任务」卡片查看任务名称、对应场景、达标线与截止时间；
  • 点击卡片下方的「开始练习」按钮，系统直接进入该任务对应的客户会话；
  • 也可在中间会话列表中选择任意客户进行自主练习（会话右侧标注「任务在身」或「陪练」）。

4.2　对话练习

进入会话后，AI 客户按预设剧本逐轮发起对话。学员可采取两种方式回复：

  • 文字回复：在底部输入框输入内容后点击发送；
  • 语音回复：按住话筒按钮说话，松开后录音在本机完成转写并填入输入框，确认后发送（录音不上传服务器）。

每轮回复提交后，系统即时给出该轮的维度得分与「是否命中本轮考察点」的判断，并提示参考表达。左侧「训练目标」清单会随命中情况自动打勾。

4.3　查看训练报告

完成全部轮次后自动生成报告，包含：

  • 综合得分与是否达到达标线；
  • 五维能力得分（开场与礼貌、需求挖掘、异议处理、方案讲解、促成推进）与逐维评语；
  • 与上一场同一场景的对比，标示各维度上升、持平或下降；
  • 逐句点评：列出客户原话、你的回复，并说明本轮考察点是什么、对应哪项能力；
  • 能力画像雷达图与全部练习均分，虚线为团队均值；
  • 下一步练习建议。

4.4　带教留言与我的成长

右侧「带教留言」展示带教主管撰写的辅导记录（按时间倒序，最多三条）。「我的成长」按入职天数推算当前所处阶段、该阶段的重点能力与目标分，并给出一句下一步建议。两项内容均随练习与辅导实时更新。

五、　教练工作台功能说明

带教主管登录后进入工作台，只能看到自己带教的学员（部门主管看本部门、管理员看全部），避免越权查看。

5.1　工作总览

首页按「今天该做什么」组织信息：

  • 今日待办：逾期未提交、临近截止、高风险学员，每条都写明原因与涉及人员；
  • 关键指标：本组达标率、平均分、待辅导人数、本周练习场次；
  • 风险分层：按红/黄/绿三档列出学员，红色为连续低分或长期未练；
  • 成长阶段分布：本组学员当前处于第几周 / 第几月，便于安排辅导重点。

5.2　学员清单与辅导

「学员清单」可按姓名搜索、按风险筛选。每行显示部门岗位、带教人、练习次数、平均分、最近趋势与操作入口。点击任意一行打开学员抽屉。

抽屉内含：能力雷达与历史成绩曲线、逐轮对话回看、成长阶段与重点维度、带教留言撰写框。撰写的辅导记录会同步到学员端的「带教留言」，形成辅导闭环。

对于判断有偏差的自动评分，主管可在对话回看中手工修正分数，系统保留原分与修正原因，可随时撤销。

5.3　对话质检

质检用于发现「AI 客服话术或评分规则不合理」的问题：主管可把某条成绩标记为正常或异常并附说明，标记为异常的对话会进入「待建场景池」，由运营认领后补充为新训练场景。

六、　运营管理后台功能说明

运营 / 培训部门使用后台完成「场景 → 任务 → 统计」的日常闭环。

6.1　数据看板

看板给出整体练习量、平均分、达标率、高风险人数，并为每项指标附「本周 vs 上周」的对照，避免孤立数字无法判断好坏。下方按部门与风险分布展示，可直接点入对应明细。

6.2　任务下发

下发采用四步向导：选择训练场景 → 勾选学员 → 填写任务名称 / 达标线 / 截止时间 → 确认下发。系统会记住上一次的场景与参数，例行下发时无需重复填写。

注意：只有「已发布」状态的场景才可下发。已发布的场景一旦被修改，会自动退回待审核状态，需重新审批后方能再次下发。

6.3　场景库与场景编辑

场景库列出全部训练场景及其训练目标、剧本轮次、审批状态与版本号，支持新建、复制、下线与删除。场景内容包含：客户人设、逐轮剧本、每轮考察点（对应能力维度）、参考话术。

场景修改保存后自动生成新版本，可随时回滚到历史版本。内容治理规则：编辑者提交审核，审核人不能是提交人本人，审批通过后才发布。

6.4　学员报告与名单管理

学员报告按成绩明细列出每位学员每场练习的分数、达标情况、场景与时间，可按部门、风险、关键词筛选，并支持导出。

学员名单支持 CSV 批量导入（姓名、部门、岗位、带教人为必填），同名同部门自动跳过；删除学员时若已有成绩将拒绝删除，避免产生无主数据。

七、　常见问题

7.1　页面能打开，但点击按钮没有反应

多为浏览器拦截了弹窗或脚本未加载完成。请刷新页面后重试；若在第三方预览器（如某些文档阅读器的内嵌网页）中打开，建议改用独立浏览器窗口访问。

7.2　语音按钮无法使用

请确认已允许浏览器使用麦克风，且语音识别服务已启动（start-all.bat）。若服务未启动，系统会自动降级为文字输入，练习不受影响。

7.3　评分与人工判断不一致

当前评分可通过两种通道完成：接入大模型时为 AI 评分，未接入时使用内置关键词引擎。带教主管可在对话回看中手工修正分数并说明原因，修正记录会保留原分，可撤销。

7.4　服务重启后数据是否还在

所有场景、任务、成绩、辅导记录均保存在程序目录下的 SQLite 数据文件中，重启不会丢失。建议定期备份该文件。

7.5　多名学员同时练习是否卡顿

系统采用单进程轻量架构，练习过程以本地交互为主，服务器仅承担数据存取。百人规模内的日常使用无明显压力；如需更大并发，建议将数据文件迁移至独立数据库并增加进程数。
