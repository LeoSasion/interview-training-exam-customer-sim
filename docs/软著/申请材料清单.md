## 三、申请流程（线上办理）

1. 打开中国版权保护中心官网 `www.ccopyright.com.cn`，注册账号并完成实名认证（单位需营业执照，1~3 个工作日审核）
2. 在线填写申请表：软件全称、简称、版本号、开发完成日期、首次发表日期、著作权人、权利取得方式与范围
3. 上传材料：源代码文档 PDF、用户手册 PDF、身份证明扫描件
4. 提交后等待受理（常规 30~60 个工作日；可申请加急）
5. 收到《受理通知书》后按期领取证书（电子证书可官网下载）

**费用**：自行申请官方免费；委托代理机构通常 800~1500 元。
