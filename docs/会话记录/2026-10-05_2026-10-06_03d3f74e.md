## 这种系统叫什么

你的截图属于 **「AI 陪练系统」的管理后台**（任务下发 / 达标线 / 学员得分报告 / 风险分层）。同一个东西在不同语境有四套叫法：

- **国内厂商侧**：AI 智能陪练 / AI 情景对练（中关村科金得助、北森、讯飞星火陪练、平安知鸟、深维智信都用这个词）
- **海外 SaaS**：AI Role-Play Training Platform，也叫 AI Sales Coaching / Conversational AI Simulator
- **培训科学侧**：Simulation-Based Learning / 刻意练习
- **工程侧**：ASR + LLM 扮演客户 + TTS + 数字人 + Rubric 评分模型

## 开源项目里最值得抄的 4 个

**① `aws-samples/sample-ai-sales-roleplay`（AWS 官方，MIT-0）—— 和你截图几乎一一对应**
它有"剧本管理列表（难度/分类/语言/创建者）"、6 步创建向导（基本信息→NPC设定→**目标设定**→PDF资料→共享→保存）、实时评估仪表盘（愤怒值/信赖度/进度）、11 项技能评分卡、排行榜。它的"目标设定"滑块就是你截图里的"达标线"。React 19 + CDK，底层 Bedrock/Transcribe/Polly + 3D 数字人 + 视频表情分析 + 合规拦截。

**② `Azure-Samples/voicelive-api-salescoach`（微软官方）—— 报告 UI 最干净**
左侧数字人视频 + 右侧实时转写，结束后出 Overall Score + 分项得分 + **逐词发音着色分析**。做学员报告页照抄这套布局最快。

**③ `crymarch/interactive-chat-simulation-template` —— 改造成本最低**
纯前端单文件，剧本用 JSON 定义，阶段式对话（3–5 阶段）+ 前置策略选择 + 一个 AI 当教练给反馈。**我已经把它拉到本地，可以直接试玩**（左侧预览面板里那个 Demo）。

**④ `beyondelastic/agentic-sales-coach` —— 含摄像头视觉分析**
每 30 秒抓一帧画面，分析表情、眼神、姿态、自信度曲线。需要考察临场仪态时单独摘出来用。

基建零件：pipecat / LiveKit Agents（实时语音）、Open-LLM-VTuber（Live2D 数字人，10k+ stars）、Dify / FastGPT（剧本编排）、RAGFlow（话术引用核查）。运营后台底座用 **Frappe LMS**（UI 现代）或 **Moodle**（最成熟）。

## 做了什么

**① 落库** —— 编辑器保存结果写入 `localStorage`（键 `TRAIN_SCENE_STORE_V1`）。之前保存只活在页面内存、刷新即丢，现在刷新/重开自动恢复。初始库从 `T.scenes` 生成，数据损坏或隐私模式下自动回落，不抛错。头部加了「重置数据」当逃生舱。

**② 版本管理** —— 每次保存自动归档快照（版本号 / 时间 / 操作人 / 变更摘要），保留最近 20 版。版本历史抽屉支持**对比**（11 个标量字段 + 目标/轮数/语音池）与**一键回滚**；回滚会生成新版本记录，不丢历史。

**③ 审批流** —— 场景走「草稿 → 待审 → 已发布 / 已下线」状态机。**只有已发布场景可下发**：场景库按钮置灰、事件 handler 二次拦截（双保险防绕过）、下发向导只列已发布场景。已发布场景被改动保存后**自动回到待审**——这是刻意的设计，不是 bug。

**④ 修掉一个真实缺陷** —— `kwGroup / kwAdd / kw-del / validateScene` 原先全都直读 `T.kw`，但场景走的是 `SCENES` 工作副本，导致**关键词和场景活在两套状态里**（改关键词不落库、刷新丢）。已抽出 `kwOf(dimId)` 统一入口，页内只剩种库初始化和 probe 对照两处合法引用。

顺带修正：`nextSceneId()` 原用 `SCENES.length+1`，删场景后会复用 id，已改用 `STORE.seq` 递增；「放弃修改」的语义也从不准确的"回原始数据源"改成"回最近一次保存版本"。

## 验证（实测，非自述）

分三段无头 Chrome 驱动，跨进程复用同一 profile 以保留 localStorage：

- **持久化**：改名+改达标线 → 保存两次 → **刷新页面** → 仍是 `持久化验证乙 / 77 / v2`，版本列表完整
- **版本归档**：`v1:首次保存` → `v2:保存修改`
- **回滚**：v2(乙/77) → 回滚 v1 → 变回 `甲/66`，生成 `v3:回滚到 v1`
- **审批 11 项断言全绿**：draft 不可下发 → 提交 `review` → 场景库 disabled 按钮 1 个 → 通过 `published` 且该场景重回可下发列表 → 向导可选 3 个 → 已发布再改自动回 `review` → 驳回回 `draft` 且原因正确回显
- **全量回归**：5 页面 `JSerr=0 ext=0`；引擎自测 35/35；内联脚本 0 语法错误
