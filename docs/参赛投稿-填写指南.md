### 5. 作品介绍（不少于 30 字，实际约 260 字）

```
面向连锁零售、快消行业的新人销售培训。新人不敢开口、第一次见客户就被压价和投诉打懵，而带教主管没时间一对一带。

学员在微信风格的对话框里，应对「你们比隔壁贵两毛五」「这批货临期了谁承担」「上次承诺的陈列费还没到账」这类真实难缠客户。客户由大模型实时扮演，会打断、会追问、会翻旧账；学员每说一句就即时评分，一场 5~6 轮。

交卷后出能力五维报告：得分、达标与否、逐轮点评（指出这一轮该做什么、你缺了哪一环），还能和同场景的上一场对比看进步。

带教主管在工作台看到谁掉队、为什么掉队，写下的辅导会直接出现在学员端「带教留言」里，学员可以回复——辅导是双向的。

运营侧管理场景库、下发任务、看看板风险分层；还能把一段真实客户聊天记录粘进来，一键生成新场景草稿。

体验方式：打开链接即可，无需注册。已预置 12 名学员、3 个场景、5 个任务和 28 场练习记录；学员端地址后加 ?as=L01 可切换成不同学员。

评分说明：接 DeepSeek deepseek-flash，金标 30 条实测相关性 pearson 0.871、平均分差 MAE 9.80 分（与人工标注分对比），可用内置脚本复现；未配模型时自动降级为关键词引擎，界面会如实标注通道。
```

### 关于「创意与场景价值」要强调的三点（口头/社媒可用）

1. **不是聊天机器人，是闭环**：评分 → 主管辅导 → 学员可见 → 可回复 → 再练，多数 AI 陪练停在"能对话"。
2. **降级不撒谎**：没有模型 Key 时界面直接标"关键词引擎评分"，不把 mock 说成 AI。
3. **场景会长大**：真实客诉对话能直接变成新场景草稿，运营从"编场景"变成"审场景"。

## 六、上线前修掉的两个问题（这轮做的，评审看不到但很关键）

### 1. 静态资源能被任意下载（安全阻断项）

`serveStatic` 原来把项目根目录下**任何文件**都发出去。实测本地：

```
GET /key.txt                  → 200   ← LLM API Key 明文
GET /server/.env.json         → 200   ← 同上
GET /server/store/training.db → 200   ← 全部学员姓名/成绩/辅导记录
```

一旦发布到公网，等于把钥匙挂在门上。已改成**扩展名白名单 + 目录黑名单**（`server/`、`docs/`、`node_modules`、`.git`、隐藏文件一律 404）。复验：敏感文件全 404，前端资源全 200。

### 2. 两个后台没法同时登录不同身份（演示阻断项）

教练台和管理端同源，token 都存 `localStorage` 的同一个 key —— 谁后登录谁覆盖。
现象：先登主管再开管理端，管理端显示"周敏（4 人）"而不是"admin（12 人）"，任务下发和审批会用错权限。

已改为 `sessionStorage`（按标签页隔离）：各页面各自登录、刷新保留、关掉即退出。复验：教练台「周敏 · 4 人」，管理端「系统管理员（admin）· 12 人」。

### 3. 云端监听地址

服务默认只绑 `127.0.0.1`，托管环境的反向代理连不进来（会 502）。已改为：有 `PORT` 环境变量时自动绑 `0.0.0.0`，本地仍绑 `127.0.0.1`。

## 七、发布后的三个提醒

1. **云端是演示库**：数据库随实例走，重启可能回到初始 28 条。评审看到的数据与截图一致即可。
2. **真实模型有调用成本**：一次完整 5 轮对练约 5~6 次模型调用。演示期若担心费用，可临时移除 `server/.env.json` 回落本地引擎（界面会自动标注）。
3. **没有 HTTPS 证书**：托管域名自带 HTTPS；若日后自己部署公网，必须加反向代理证书——这一条已写在 README 的已知限制里。
