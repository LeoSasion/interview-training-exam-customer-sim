金标集校准（Rubric 与人工一致性）

金标集是人工双盲标注的对话样本。校准会计算「模型综合分 vs 人工总分」的 Pearson 相关系数与 MAE，用来验证评分口径是否与人类判断一致（目标：相关系数 ≥ 0.8、MAE ≤ 8）。样本越多结论越可靠 —— 可在下方批量导入。

数据备份

全部数据在一个 SQLite 文件里，建议定期快照。VACUUM INTO 生成一致性副本，无需停服；自动保留最近若干份。

金标集导入

粘贴 JSON 数组，每项含 id / sceneId / turnIndex / customerText / learnerText / humanScores（d1–d5）/ humanTotal / annotator。同 id 覆盖更新，用于持续扩充人工标注样本。
