feat(P29-P31): 辅导双向回复 / 学员练习记录与历史回看 / 从真实对话生成场景

一、P29 辅导双向（学员可回复带教留言）
问题：辅导是单向的（教练写 → 学员看）。学员想说"我试了但客户直接打断我"却无处可发，
而这句话恰恰能告诉教练「场景/话术设计可能要改」。

- db.js：幂等迁移给 coach_notes 加 reply_to（老库启动自动补列）
- lib/coach.js：新增 replyCoachNote()，与教练留言共用 insertNote() 写库
  三条硬校验：learnerId 必须存在 / replyTo 必须属于该学员 / 只允许一层
- 路由：走独立 POST /learner/coach-notes/reply（practice 档）。
  没有把 /coach-notes 放开——那是 staff 写入接口，匿名放开等于可代任意学员写辅导
- 学员端：留言下「回复」→ 内联输入 → 发送；已有回复挂回父留言下，回复过就不再给按钮
- 教练抽屉：学员回复以高亮块显示在对应留言下

实测：L01/L02 各回一条 → type=学员回复、by=学员名、replyTo 正确；
L02 回复 L01 的留言 → 403；缺 replyTo → 400；回复回复 → 400。

二、P30 学员练习记录 + 历史逐轮回看
问题：学员只有"最近一次报告"，想回看"上周五那场为什么只有 50 分"没入口。

- lib/records.js：listRecords 支持 practice（强制 learnerId、跳过范围过滤）；
  新增 learnerTurns() 按记录归属校验
- 路由：GET /records 放开到 practice；新增 GET /learner/records/:id/turns
- 学员端：「练习记录」卡（时间/场景/分数/轮次）+ 独立覆盖层回看（分数、五维、逐轮对话）
  刻意不复用「训练报告」页——那页绑定当前会话状态，历史数据塞进去会把动作搞乱
- assets/ai-bridge.js：records() / learnerTurns()

⚠️ 顺带堵了一个越权：open 模式下无凭据请求会被 auth.resolve 兜底成 admin，
   于是"匿名"其实是全量权限——学员端正好走无凭据路径，前端漏传 learnerId 就会把
   全库成绩渲到某个学员屏幕上。现加 requireLearnerIdForAnonymous：
   无凭据且无 learnerId → 400（/records 与 /coach-notes 都加）。
   实测：无凭据读全库 → 400；带 learnerId → 只返回本人；教练带 token → 全库 28 条。

三、P31 从真实对话生成场景草稿
问题：建场景要手写人设+6 轮剧本+每轮考察点，约 40 分钟一个；而运营手上最多的素材
是真实客户聊天记录。

- 新增 lib/scene-draft.js：POST /scenes/draft，把对话交给模型起草
  场景名 / 客户画像 / 5 轮台词 / 训练目标（绑定 d1..d5）/ 分类难度达标线
- 输出一律归一化+钳制：分类与维度白名单、目标≤8、台词秒数 3-60、数量不等给 warning
- 没有模型 Key 时明确报错，不编假草稿（关键词引擎做不到"从对话提炼"）
- 空 content / 坏 JSON 自动重试一次（deepseek-flash 实测偶发空返回）
- 管理端：「✨ 从对话生成」→ 抽屉粘贴 → 生成结果页（含 warnings）→ 放进编辑器
- 草稿存为 draft 状态，仍须「提交审核 → 审批」才能下发，不绕过 canEdit/canAssign 闸门
- 路由 /scenes/draft 按铁律 13 排在 /scenes/:id 之前

实测（deepseek-flash，输入 291 字真实对话）：生成「便利店长追损耗与价差」，
5 条目标覆盖 4 个维度、5 轮台词保留原对话的开场与比价细节、分类「客诉安抚」、达标线 68；
放进编辑器后字段全部正确落位。
