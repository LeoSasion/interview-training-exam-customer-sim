feat(P28): 接入真实 LLM（DeepSeek deepseek-flash）+ 完成真实校准

用户提供了 key.txt，接入后跑通全链路。过程中发现 key 一直 401 的真正原因。

## key 401 的真因：文件里混了中文标点和空格
key.txt 的内容是 `deepseek V4.1：sk-88c...9d9a` —— 一整行里包含了 provider、模型版本、
**全角冒号「：」**和空格。我一开始把整行当 API Key 发出去，DeepSeek 返回
`Authentication Fails (governor)`，换成 /v4 路径后变成 `api key to_str failed`（更准确：
key 无法解析）。按冒号切分、取 `sk-` 开头那一段（35 字符）后立刻通了。

## 接入配置
写入 `server/.env.json`（config.js 原生支持，环境变量优先）：
  LLM_BASE_URL = https://api.deepseek.com/v1
  LLM_MODEL    = deepseek-flash
⚠️ `server/.env.json` 与 `key.txt` 已加入 .gitignore，`git check-ignore` 确认不会入库。

## 顺带修正两处「会假装全绿」的地方
- `calibrate.js`：样本数不足时明示「X 条评分失败，指标基于其余样本」，
  失败率 >10% 直接标红（真实跑就遇到 28/30，不报出来等于骗人）
- `selftest` 校准断言：原来要求「全量无失败」，真实模型每次失败 1~2 条就会假红 →
  改为「成功率 ≥ 90%」，既容忍模型波动又不放过真问题
