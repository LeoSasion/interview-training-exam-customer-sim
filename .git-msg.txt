二、修掉的上线阻断问题（评审看不到，但不修会出事）

1. 静态资源可被任意下载（**安全**）
   serveStatic 原来把项目根目录下任何文件都发出去，实测：
     GET /key.txt                  → 200  ← LLM API Key 明文
     GET /server/.env.json         → 200  ← 同上
     GET /server/store/training.db → 200  ← 全部学员姓名/成绩/辅导记录
   本地无所谓，发布到公网等于把钥匙挂在门上。
   改为扩展名白名单 + 目录黑名单（server/ docs/ node_modules .git 隐藏文件一律 404）。
   复验：敏感文件全 404，前端资源全 200。

2. 两个后台无法同时以不同身份登录（**演示阻断**）
   token 存 localStorage 同一个 key，谁后登录谁覆盖：
   先登主管再开管理端，管理端显示"周敏（4 人）"而不是 admin（12 人），
   任务下发/审批会用错权限——而演示动线正是三个页面同时开着。
   改为 sessionStorage（按标签页隔离）：各自登录、刷新保留、关掉即退出。
   复验：教练台「周敏 · 区域教练 / 4 人」，管理端「系统管理员（admin）/ 12 人」。

3. 云端监听地址
   默认只绑 127.0.0.1，托管环境反代连不进来（会 502）。
   改为：有 PORT 环境变量时自动绑 0.0.0.0，本地仍绑 127.0.0.1。
