feat(P19): 键盘可达性——焦点环、焦点陷阱、行级 Enter/Space

背景：三个页面此前**没有任何焦点管理**，键盘用户基本没法用。

一、焦点环（三页都是 0 处 :focus-visible）
- shell.css（教练台 + 管理端）：`:focus-visible` 2px 品牌绿环，鼠标点击不打扰；
  输入框改用轻量 box-shadow 避免与自定义边框双重描边
- 学员端（自带样式）：微信风格里语音/电话/发送都是圆形小图标，键盘用户完全看不到焦点落在哪；
  聊天输入框自身 outline:0，改用 `.ibox:focus-within` 父容器环补上

二、真正的缺陷：学员行根本不可聚焦
`<tr data-go-coach>` 用 cursor:pointer 伪装成可点，但 **`<tr>` 默认不可聚焦**——
键盘用户无法用 Tab 选中任何学员行，也就**永远打不开辅导抽屉**（主要功能之一）。
修复：行/待办卡片加 `tabindex="0" role="button"` + `aria-label`，并让 Enter / Space 等价点击
（只在行自身上生效，行内按钮仍各自响应）。

三、焦点陷阱与归位
- 新增 trapFocus(container)：Tab 在容器内循环（首↔尾），关闭时释放监听并把焦点还给打开它的元素
- 接入：管理端页内确认框、管理端抽屉、教练台抽屉
- 真机完整闭环验证：行 tabindex=0/role=button → 可聚焦 ✅ → **Enter 打开抽屉** ✅ →
  焦点进入抽屉按钮 ✅ → Esc 关闭 → **焦点回到原行** ✅
